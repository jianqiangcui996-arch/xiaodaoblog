<h1 id="老电视自救指南：给-PPTV-55C4-去广告、装-Kodi-看直播、换第三方桌面"></a>老电视自救指南：给 PPTV 55C4 去广告、装 Kodi 看直播、换第三方桌面</h1><p>一台 2018 年前后智能电视的 ADB 折腾全记录</p>
<p>作者：家里的网络管理员 ｜ 设备：PPTV 55C4 ｜ 难度：★★☆☆☆（会敲命令就行）</p>
<p>  家里的 PPTV 电视越用越闹心：开机一堆广告、自带的”直播”源大半打不开、遥控器还老被劫持去推流媒体。它本质就是一台 Android 盒子，那能不能像折腾手机一样，用 ADB 把它收拾干净？答案是能，而且<strong>全程不用 root</strong>。这篇把踩过的坑一次讲清。</p>
<h2 id="一、先看清你的”战场”">一、先看清你的”战场”</h2><p>动手前先摸清设备底细，后面每一步都围着它转：</p>
<pre><code>- **电视**：PPTV 55C4，系统 PPOS 7.2.84，底层是 `Android 5.1.1`（SDK 22，32 位 `armeabi-v7a`），**未 root、bootloader 锁定**。
- **路由器**：电信定制的中兴 ZXHN E500，功能很弱，只支持 URL 黑名单，做不了端口转发之类的精细控制。
- **电脑**：一台 Windows 笔记本，装好 Android Platform-Tools（adb）和 scrcpy 即可。
- **网络**：电视走 WiFi，拿的是路由器 DHCP 分配的局域网地址——**这个 IP 会变**，后面会反复被它坑。
</code></pre>
<p>  为什么强调”未 root &#x2F; 锁定”？因为这决定了我们能走多远。好在本文所有操作都在”免 root”范围内，风险比刷机小得多。</p>
<h2 id="二、第一步就劝退一半人：用-ADB-连上电视">二、第一步就劝退一半人：用 ADB 连上电视</h2><p>电视的”开发者选项 → 网络调试（ADB over 网络）”打开后，电脑上就能：</p>
<p>  adb connect 192.168.x.x:5555<br>adb devices          # 看到 device 就成功了</p>

<p>需要注意的是：<strong>先确认包名再 disable</strong>，别拿”看着像广告”的包下手，否则可能把桌面或设置禁掉。禁用后用 <code>pm list packages</code> 核对一遍即可。</p>
<p>效果立竿见影：开机广告没了，屏保不再弹购物，遥控器也不会被半路劫去推 App。全程没碰系统分区，想恢复只要 <code>enable</code> 回来。</p>
<h2 id="四、装上-Kodi-21-3，看-IPTV-直播">四、装上 Kodi 21.3，看 IPTV 直播</h2><p>我想要的是”一个遥控器看所有直播源”，Kodi + PVR IPTV Simple Client 是最省事的方案。电视自带的是老掉牙的 Kodi 19.1，HLS 直播经常抽风，于是升级到官方 <strong>Kodi 21.3（Omega）</strong>。这里踩了两个大坑：</p>
<h3 id="坑-1：升级后-Kodi-启动卡死">坑 1：升级后 Kodi 启动卡死</h3><p>21.3 起来后卡在 <code>waiting for add-ons to update...</code>，Web 服务一直起不来。查日志发现是几个 <strong>Kodi 19 时代的 inputstream 插件（ffmpegdirect &#x2F; rtmp）跟 21 不兼容</strong>，把启动流程堵死了。把它们移走后，Kodi 自带的仓库很聪明，<strong>自动把插件更新到了 21.x 版本</strong>：</p>
<pre><code>- pvr.iptvsimple → `21.11.0`
- inputstream.adaptive → `21.5.23`
- inputstream.ffmpegdirect → `21.3.8`
- inputstream.rtmp → `21.1.2`
</code></pre>
<h3 id="坑-2：HLS-报-“Error-creating-demuxer”-不一定是-Bug">坑 2：HLS 报 “Error creating demuxer” 不一定是 Bug</h3><p>本地生成的 MP4&#x2F;HLS 测试流都能正常播（<code>speed=1</code>），证明播放器本身没问题。但点某些频道就报 <code>OpenDemuxStream - Error creating demuxer</code>。排查下来，罪魁是源的 <strong>master playlist 写了非法的 <code>#EXT-X-STREAM-INF:BANDWIDTH=1</code></strong>，Kodi 解析 variant 选择器时直接崩了。改用它的 variant（清晰度）直链播放，立刻 1080p 正常。</p>
<p>经验：遇到 HLS “demux 失败”，先怀疑源 playlist 格式是否合法，再怀疑播放器。别急着给 Kodi 扣”兼容性差”的帽子。</p>
<h3 id="一个关键真相：播放失败，锅不在-Kodi">一个关键真相：播放失败，锅不在 Kodi</h3><p>最初用户报”一个台都播不了”。我把三个 m3u8 播放列表里的 <strong>1668 个频道 URL 全量探活</strong>，结果只有 <strong>1 个</strong>能连通，其余全部超时&#x2F;失效（包括某高校 IPTV 测试源这种曾经能用、如今 100% 丢包的）。</p>
<p>也就是说：<strong>播放器、网络、PVR、HLS demux 全部健康，”播不了”纯粹是 IPTV 源大面积失效</strong>。唯一存活的那个直播源，用上面的 variant 直链法在电视上实测能放 1080p。</p>
<p>  结论很现实：免费公开 IPTV 源的稳定性几乎没有。真要长期看，得有稳定可靠的源（合规渠道），而不是指望网上随便下的 m3u8。</p>
<h2 id="五、换上当贝桌面-开机自启">五、换上当贝桌面 + 开机自启</h2><p>原厂 PPOS 桌面广告多、还不顺手，换成第三方 TV 桌面体验立刻不一样：</p>
<pre><code>- **当贝桌面**（`com.dangbei.tvlauncher`）：TV 向的 launcher，干净好用，顺带带了当贝市场。
- **Autostart**（`com.autostart`）：配一下，让电视开机自动拉起 Kodi（或你指定的 App），省得每次手动找。
- **当贝文件管理器**（`com.tv.filemanager`）：在电视上管理 U 盘/局域网文件，传 m3u8 源很方便。
</code></pre>
<p>安装就是常规 <code>adb install -r xxx.apk</code>，推到 <code>/sdcard/Download/</code> 再装。</p>
<p>  顺带说一句很多人会踩的坑：<strong>KingRoot、Magisk 这类 root 工具，在这台锁 bootloader、未 root 的电视上装了也 root 不了</strong>。Magisk 要 patch boot.img + 第三方 recovery 才能刷；KingRoot 在定制系统上基本被挡。它们装上只是占地方，还可能带来隐私&#x2F;广告风险。<strong>本文所有改造都不需要 root，别去点”获取 root”。</strong></p>
<h2 id="六、用-scrcpy-把电视”投”到电脑上遥控">六、用 scrcpy 把电视”投”到电脑上遥控</h2><p>想在大屏幕上操作、或者懒得找遥控器时，scrcpy 能把电视画面投到电脑并反向控制。针对这台电视我写了个一键脚本，重点解决了 IP 变化的问题：</p>

启动后电脑上弹个窗口，鼠标当遥控器、键盘能输字，延迟在局域网里基本无感。**前提是电视&quot;网络调试&quot;是开着的**——所以每次要用时，若连不上，先回电视重开一下网络调试（见第二节）。

  
## 七、那些年一起踩过的坑（清单）

  

    - **IP 动态**：脚本里用 MAC 反查，别写死。
    - **网络调试会自己关**：待机/重启后回电视重开。
    - **adb offline 僵死**：PC 端重启没用，电视端重开网络调试重启 adbd。
    - **Kodi 文件路径**：用绝对路径 `/sdcard/...`，别写 `file:///` 三斜杠（会被误解析成 `file://` 导致&quot;播放失败&quot;假象）。
    - **HLS demux 报错**：先查源 playlist 的 `BANDWIDTH` 等字段是否合法，必要时用 variant 直链。
    - **升级 Kodi**：旧版 inputstream 插件不兼容会卡启动，移走让仓库自更新即可。
    - **别迷信 root 工具**：锁 bootloader 的设备，KingRoot/Magisk 装了也白装。
    - **源才是命门**：播放器没问题，免费 IPTV 源大半已死，得有稳定合规源。
  

  

  
## 结语

  

折腾一圈下来，这台老 PPTV 从&quot;广告弹窗遥控器被劫持&quot;变成了&quot;干净桌面 + Kodi 直播 + 电脑反向遥控&quot;的自在设备，而且**全程零 root、零刷机、随时可还原**。最大的收获其实不是具体命令，而是排查思路：**先分层定位（网络→连接→播放器→源），别一上来就怪软件。**
