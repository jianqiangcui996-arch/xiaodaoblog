<blockquote>
<p>一台 2014 年的 i5 + 16GB 内存的 Win10 老机器，开机后内存就吃掉一半多。花半小时做了次”开机体检 + 微创手术”，分享给同样被老电脑启动拖累的朋友。</p>
</blockquote>
<h2 id="一、为什么要折腾">一、为什么要折腾</h2><p>最近这台主力机的体感是：开机进桌面后要”愣”好一会儿才顺手。看一眼任务管理器——16GB 内存，刚开机空闲就只剩 7GB 出头。</p>
<p>老平台的 CPU 本来就弱（i5-4590，四核），开机阶段几十个自启动进程和服务一起抢 CPU、抢磁盘，慢是真有原因的。</p>
<p>于是我决定系统地查一遍：<strong>开机启动项、系统服务、计划任务</strong>。这里说句公道话，很多”电脑慢”并不是硬件不行，而是十年积攒下来的自启动残留没人管。</p>
<h2 id="二、先摸清家底：三个检查入口">二、先摸清家底：三个检查入口</h2><p>不用装任何第三方工具，Windows 自带的信息就够用：</p>
<p><strong>1. 启动项</strong>——看三个地方：</p>
<ul>
<li>任务管理器 →”启动”标签页（最直观，但看不到全貌）</li>
<li>注册表 Run 键（真正的”账本”）：<ul>
<li><code>HKCU\Software\Microsoft\Windows\CurrentVersion\Run</code>（当前用户）</li>
<li><code>HKLM\Software\Microsoft\Windows\CurrentVersion\Run</code>（所有用户）</li>
<li><code>HKLM\Software\WOW6432Node\...\Run</code>（32 位程序）</li>
</ul>
</li>
<li>启动文件夹：<code>shell:startup</code> 和 <code>shell:common startup</code></li>
</ul>
<p>用命令快速看一眼注册表启动项：</p>

<p><strong>2. 服务</strong>——重点看”自启动但不用”的：</p>

<p>微软官方的 svchost 服务基本别碰，重点筛<strong>第三方路径</strong>的自启动服务。</p>
<p><strong>3. 计划任务</strong>——开机&#x2F;登录触发的隐藏大户：</p>

<h2 id="三、体检报告里最意外的三个发现">三、体检报告里最意外的三个发现</h2><h3 id="发现①-一个”幽灵用户会话”在偷偷吃内存">发现① 一个”幽灵用户会话”在偷偷吃内存</h3><p>机器上有两个账户。检查时发现：另一个账户的会话虽然处于”已断开”状态，但人走了、”房间”没退——一整排按用户启动的服务还在后台常驻，白白占几百 MB 内存。</p>
<p>这个坑非常隐蔽：任务管理器的启动项里根本看不到它。<strong>断开 ≠ 注销</strong>，不用了请选”注销”。</p>
<h3 id="发现②-卸载干净的安全软件，才是对系统好">发现② 卸载干净的安全软件，才是对系统好</h3><p>体检发现一个很典型的”半卸载”样本：某国产安全软件的托盘程序还注册在开机启动里，但进程根本没在跑（服务也是”自动启动、实际停止”）——典型的卸载不干净。而 Windows Defender 其实在正常工作，双杀毒软件共存毫无意义，只会拖慢开机。</p>
<p>处理方式：删掉它的 Run 启动项 + 删除残留服务，最后用官方卸载器&#x2F;清理工具把残留目录请出去。<strong>先备份注册表，再动手。</strong></p>
<h3 id="发现③-“自动启动”的服务，有一大半其实从没运行过">发现③ “自动启动”的服务，有一大半其实从没运行过</h3><p>清点名册时发现 6 个服务设成了”自动”，但常年 Stopped——它们不是不需要，就是按需才用。这类服务改成”手动”几乎零风险：Windows 需要时会自动拉起它们，白白开机自启只是徒增负担。</p>
<figure class="highlight powershell"><table><tr><td class="gutter"><pre><span class="line">1</span><br><span class="line">2</span><br></pre></td><td class="code"><pre><span class="line"><span class="comment"># 查看某服务当前状态</span></span><br><span class="line"><span class="built_in">Get-Service</span> <span class="literal">-Name</span> <span class="string">&#x27;MapsBroker&#x27;</span></span><br></pre></td></tr></table></figure>

<p>另外还揪出一个每次登录都静默失败的计划任务（上次结果代码 1）——这种”僵尸任务”既拖慢登录又报错给谁看呢？不需要就直接删。</p>

<p>改完后，真正有实质负担的第三方自启只剩网络代理等少数几个确实在用的。<strong>系统服务从 73 个自启动降到 65 个，开机自启进程减少 5 个以上，预计释放内存 0.5~1GB</strong>——对老平台来说，登录到可用的等待时间有可感知的缩短。</p>
<h2 id="五、抄作业：安全清单与红线">五、抄作业：安全清单与红线</h2><p><strong>动手前，务必先备份</strong>（注册表一键导出，改坏了能还原）：</p>
<figure class="highlight bat"><table><tr><td class="gutter"><pre><span class="line">1</span><br></pre></td><td class="code"><pre><span class="line">reg export &quot;HKCU\Software\Microsoft\Windows\CurrentVersion\Run&quot; run_backup.reg</span><br></pre></td></tr></table></figure>

<p><strong>这些不要乱动</strong>（我保留的白名单）：</p>
<ul>
<li>杀毒&#x2F;防火墙：Defender 全家桶（WinDefend、wscsvc、mpssvc）</li>
<li>网络相关：无线局域网（WlanSvc）及<strong>无线网卡厂商自己的服务</strong>——有的电脑用的是 USB 网卡，厂牌服务一停直接断网</li>
<li>开发依赖：WSL 服务</li>
<li>外设依赖：打印后台处理（Spooler）</li>
<li>你自己主动部署的隧道&#x2F;代理&#x2F;网关类服务</li>
</ul>
<p><strong>原则一句话：只删”确定的残留”，只改”自动却从不运行”的，拿不准就设”手动”而不是”禁用”。</strong></p>
